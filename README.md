# task26100560

站点证书分阶段轮换库（纯内存状态、进程内设备模型、本地生成真实自签 X.509 证书）。

## 结构

- `cert_rotation/certs.py` — 本地生成真实自签 X.509 证书与指纹计算。
- `cert_rotation/device.py` — 进程内设备模型：完整配置（身份证书 + 各邻站信任集合）、
  版本递增、只原子应用更高版本配置、应用后返回回执。
- `cert_rotation/library.py` — 轮换库：发起轮换 / 人工确认 / 获取待下发配置 / 提交回执。
- `tests/test_rotation.py` — 自动化测试，依据设备实际身份与对端实际信任集合独立核对。

## 轮换流程

1. `start_rotation(site)`：生成候选证书，向各邻站下发"追加信任候选证书"的配置。
2. 邻站全部应用后进入 `AWAITING_CONFIRM`；此前本站不得使用候选身份。
3. `confirm_rotation(site, fingerprint)`：人工确认指定候选证书（旧确认无效），
   生成本站切换身份的配置。
4. 本站应用后，向邻站下发"只信任新证书"的配置，清除旧证书信任。
5. 邻站全部应用后报告 `complete`；之后允许再次轮换。

配置投递与回执由上层搬运，可乱序、重复、延迟；库只依据回执推进阶段，
且每站点的版本号单调递增，旧版本配置/回执不会改变设备或库的状态。

## 运行测试

```sh
python3 -m pytest tests/ -q
```
